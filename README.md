# Вариант 7 — Доля недоступных узлов

Дежурный получает процент недоступных узлов из готового результата мониторинга. Сетевые запросы не выполняются.

В available true означает доступность. Run возвращает целый процент недоступных: countFalse * 100 / длина с округлением вниз. Пустой массив даёт 0. Длина не превышает 1000.

Исходник ReviewTask.cs намеренно содержит ошибки.
Не меняйте ожидаемые значения в Program.cs ради успешного запуска.

Запуск: dotnet run --project ReviewLab.csproj

- T01: Четверть; ожидается [25].
- T02: Треть; ожидается [33].
- T03: Все доступны; ожидается [0].
- T04: Все недоступны; ожидается [100].
- T05: Пустой; ожидается [0].
